# Очередь повторов агентов

Сюда раз в неделю каждый разработчик дописывает, на чём агенты спотыкались в его сессиях. Правки по очереди делаются отдельно: так видно общие причины, которые по одной сессии не заметишь. Порядок — в [workflow.md](workflow.md#разбор-сессий-как-устроен).

## Как дописывать

Новая запись — сверху, под «Записи»:

```markdown
### YYYY-MM-DD — Имя, окно YYYY-MM-DD…YYYY-MM-DD

| Класс          | Случаев | Пример                                  | Уровень | Правка        |
| -------------- | ------- | --------------------------------------- | ------- | ------------- |
| <одна причина> | 3       | <короткая цитата поправки без секретов> | lint    | <что сделать> |

Потери времени: <долгий поиск, тяжёлые вызовы, нехватка доступа | —>
```

Уровень — самый высокий из работающих: архитектура, типы, lint, тест, правило. Без секретов, данных клиентов и длинных цитат.

После разбора класс, который закрыли, помечается ссылкой на коммит: `закрыто — abc1234`.
